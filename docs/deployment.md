# 阿里云与微信上线准备

## 当前交付边界
已经提供真实 API、SQLite 数据库、图片文件存储、原生小程序源码、浏览器预览和审核后台。云端部署模板尚未在你的 ECS 上运行；微信 AppID 未配置，未做微信开发者工具编译、真机登录、上传与审核。浏览器预览不是微信小程序安装包。

## 一、先准备账号和域名
1. 按真实的“闲置信息发布、线下交易”功能向微信确认主体和服务类目；按反馈提供材料。
2. 完成小程序注册、必要认证与小程序备案，取得 AppID。AppSecret 只放服务器环境变量。
3. 阿里云中国内地 ECS 建议 2 核 4GB、60–80GB SSD、3–5Mbps 起步；完成域名实名认证和后端域名 ICP 备案。
4. 安全组开放 80/443，SSH 仅限管理员 IP；不对公网开放 3000 和数据库端口。

## 二、部署后端
ECS 安装 Docker Engine、Compose 插件、Nginx 后，把仓库复制至专用目录。以下命令在 Linux 执行：

```sh
cp .env.example .env
# 编辑 .env：填写微信 AppID、AppSecret、学校名称、管理员密码和签名密钥。
# 密码至少 16 字符，签名密钥至少 32 字符。可用下面命令生成独立的随机值：
openssl rand -hex 32
docker compose up -d --build
docker compose logs --tail=50 market
curl http://127.0.0.1:3000/api/health
```

配置 deploy/nginx.conf.example 中真实域名和有效 HTTPS 证书，启用前运行 `nginx -t`。需要一个可信反向代理且 3000 只监听宿主机回环地址，才能使用 TRUST_PROXY=1。

正式服务不包含演示账号入口或演示商品。不要用 `npm run dev` 对外提供服务。浏览器端正式环境只提供公开展示与管理员后台，普通用户使用微信小程序登录。

本期图片存在服务器持久化卷中，便于试运行。尚未接入 OSS；磁盘、访问量增长后再迁移。上传图片先经格式验证、压缩与 EXIF 去除；商品在管理员审核前不公开。需安排实际审核人员，代码不能替代运营审核。

## 三、微信配置与开发者工具
1. 微信开发者工具导入 `miniprogram` 目录，换成你自己的 AppID。
2. 修改 miniprogram/config.js 的 API_BASE 为 `https://你的域名`，不含 /api 后缀。
3. 微信后台为 request、uploadFile、downloadFile 配置相应 HTTPS 合法域名，按当前平台要求配置图片访问与隐私声明。
4. 按实际功能填写用户隐私保护指引，包括用户上传图片、主动填写联系方式与登录标识。将示例使用须知替换为真实运营者信息、联系渠道、保存期限和注销流程。
5. 开发者工具本机体验可以暂时关闭本地“校验合法域名”，用 http://127.0.0.1:3000；这仅用于开发。真机的 127.0.0.1 指手机自己，不能连接电脑服务；真实体验使用已部署的 HTTPS 后端。
6. 编译、真机测试微信登录与选图授权，验证发布→审核→浏览→收藏→联系→已售。管理员从 `https://你的域名/admin.html` 登录。
7. 准备真实演示内容和审核说明，通过审核后由管理员发布。

不自动核验学生身份。若确实需要限制“只有本校学生”使用，需再接学校授权的验证方式；学校名称或微信登录不能作为学生身份证明。

## 四、备份和恢复
```sh
docker compose exec market node scripts/backup.js
```
脚本输出备份目录，包含一致性 SQLite 快照和图片。把目录复制到独立存储（例如备份用 OSS），不能只保留同一台 ECS 的副本。数据库与联系方式属于敏感业务数据，备份不设公开访问权限。

恢复时先停止写入服务，保存当前卷的副本，再将备份中的 market.sqlite 和 uploads 恢复到新卷；不要向运行中的数据库覆盖文件。启动后检查商品数量、图片、收藏、审核状态，重启验证持久化。密钥与微信凭据用独立安全方式保存，备份不含 .env。

## 五、正式运营限制
- 本期无订单、支付、佣金、付费置顶、配送系统或即时聊天。
- 单实例、单 SQLite 文件，不可让多台服务器并发共享此文件；扩展时迁移数据库。
- 人工审核、举报处理、账号数据删除请求目前需要运营者介入。
- 未绑定商品的上传文件暂不自动清理；监控磁盘并在后续加入保留期清理任务。
- 未来收费置顶需另行核实主体、支付准入及 iOS 相关规则，不包含在当前发布包中。
