# MVP 验证记录

验证日期：2026-09-16。运行环境：Windows，Node.js 24.14.1，本机 Microsoft Edge（Playwright）。

## 已通过
- `npm run check`：所有 JavaScript 语法、JSON 文件、小程序页面文件完整性通过；10 个自动化测试通过。
- `PLAYWRIGHT_CHANNEL=msedge npm run test:e2e`：3 个真实浏览器端到端测试通过。
- `npm audit --omit=dev`：0 个已知生产依赖漏洞。
- 主流程：上传照片→发布等待审核→管理员通过→第二用户搜索→详情与简介→收藏→联系信息→卖家已售→收藏失效状态→取消收藏。
- 安全与边界：鉴权、越权编辑、图片所有权、未审核商品隐藏、修改后重新审核、非法图片、金额精度、必填字段、举报/下架、退出失效、跨站请求拦截、生产关闭演示登录。
- 数据：活动 WAL 数据库备份可独立恢复，图片一并保存，原数据库重开后数据仍在。
- 小程序逻辑：发布请求字段、失败保留输入、阻止上传中提交、搜索响应竞态、登录同意状态。
- 页面：1440px 桌面与 390px 手机视口检查，无横向溢出；手机发布表单可操作，提交失败保留输入。已查看桌面与手机截图并调整手机主视觉换行。
