# 盒集手机界面原型

双击 `heji-mobile.html` 即可离线预览，也可使用本地静态服务器打开。
这是独立的静态界面，不连接业务后端。商品、简介、数量、地点与反馈均为演示数据；联系卖家不会发送消息，不创建订单、不支付。

包含顶部即时搜索、每 5 秒循环横幅、商品详情与线下联系说明、发布入口、收藏交互和交易反馈演示。桌面侧栏可修改文案、主题颜色并导出 HTML。

商品卡片的图片、标题与空白区域均可打开详情；收藏按钮独立操作。键盘聚焦卡片后可用 Enter 或空格打开。搜索匹配结果使用相同详情。

本次纳入 Git 前的仓库基线为 `7d97f8d`；业务应用保持不变。回归测试位于 `tests/browser/prototype.spec.js`，随 `npm run test:e2e` 运行。
